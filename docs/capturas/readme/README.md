Todas son capturas reales del juego; ninguna es una maqueta. Se recortaron las franjas negras laterales del Galaxy S22+ para dejar el área de juego en 16:9 y se redujeron a 960 px de ancho. Sólo el gráfico de la ficha conserva su tamaño original (1024 × 500).

Los originales están en el respaldo privado del propietario, `Respaldo Five Nights at ESCOM Play Store`. Ese respaldo no se versiona porque contiene la llave de firma.
